# DevWeb Canvas

[OBJETIVO DO PROJETO]
Desenvolver o "DevWeb", uma plataforma de ponta para ensino de tecnologia, programação e desenvolvimento web. O objetivo primário é construir um site que seja uma verdadeira obra de arte digital, com um nível de criatividade e profissionalismo dignos de vencer prêmios internacionais de web design (como Awwwards). O projeto servirá tanto como vitrine para os cursos oferecidos (HTML, CSS, JavaScript e Python) quanto como um simulacro imersivo do "Dashboard do Aluno" (área logada com atividades e aulas práticas), com interações ricas, layouts fora da caixa e navegação cativante.

[DADOS DA MARCA E CONTEÚDO]

Nome do Projeto: DevWeb

Nicho: Educação em Tecnologia e Programação Web.

Vibe/Tom: Ultra-criativo, futurista, profissional, imersivo, inovador (evitar templates engessados; explorar assimetria, glassmorphism, animações de scroll ou elementos que remetam à criatividade no código).

Imagens: Como não foram fornecidas imagens específicas, utilize imagens de placeholder de altíssima qualidade (via Unsplash ou similares) que representem arte abstrata digital, setup de desenvolvedores, ciberespaço e elementos de UI/UX modernos.

[ARQUITETURA DE SEÇÕES]
A página deve fluir como uma narrativa visual contínua. Estruture as seguintes seções de forma fluida e altamente criativa:

Hero Section (Imersão): Um cabeçalho de impacto. Tipografia enorme e criativa, talvez brincando com tags de código misturadas ao texto. Um Call to Action (CTA) magnético para "Iniciar a Jornada Dev". O fundo deve ser visualmente deslumbrante (explorar efeitos visuais ou geometria abstrata).

A Jornada do Desenvolvedor (Etapas de Aprendizado): Em vez de uma lista chata, crie um roadmap gamificado ou uma linha do tempo sinuosa e interativa, mostrando as fases desde a base (HTML) até a lógica avançada (Python).

Catálogo de Cursos (Tabela/Grid Premium): Uma apresentação detalhada e estilizada das disciplinas. Pode ser uma tabela moderna ou cards 3D interativos contendo:

Curso 1: HTML | Nível: Iniciante | Duração: 20h

Curso 2: CSS | Nível: Intermediário | Duração: 30h

Curso 3: JavaScript | Nível: Avançado | Duração: 50h

Curso 4: Python | Nível: Lógico/Backend | Duração: 40h

Dashboard do Aluno (Simulação da Área Prática): Uma seção que simule a interface de estudos logada. Deve conter:

"Minhas Aulas Práticas" (com miniaturas de vídeo simuladas).

"Atividades e Desafios" (com barras de progresso ou gráficos radiais super bem desenhados).

Um mini-painel de estatísticas de aprendizado.

Rodapé (Footer): Moderno, clean, contendo links de navegação, informações de contato e a assinatura do autor.

[DIRETRIZES DE DESIGN SYSTEM]
Utilize rigorosamente a 'Skill de Design Front-end' e o arquivo de Design System em anexo. A harmonia visual, paleta de cores, tipografia, espaçamentos e microinterações devem derivar exclusivamente do arquivo fornecido, criando um layout refinado e de alta conversão. Puxe os limites da criatividade deste Design System para criar algo visualmente memorável.

[REGRAS TÉCNICAS INEGOCIÁVEIS]

Arquitetura CSS: Integre todo o CSS diretamente no arquivo HTML, utilizando a tag . Não gere arquivos CSS externos.

Dados Padrão de Placeholder: Sempre que o layout exigir dados de preenchimento para perfis, portfólios, rodapés ou áreas de autor principal, utilize os seguintes dados: Nome Principal - FALCONE E PAULO, tag line - aluno de d.s.
